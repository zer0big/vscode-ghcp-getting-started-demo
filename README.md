# VS Code + GitHub Copilot 시작하기 데모

이 프로젝트는 VS Code 공식 튜토리얼(https://code.visualstudio.com/docs/copilot/getting-started)을 따라 제작된 작업 관리 웹 앱입니다.

## 주요 기능
- 작업 추가 / 완료 표시 / 삭제
- 전체 / 진행 중 / 완료 필터
- 다크 모드 토글 (시스템 설정 연동)
- localStorage 데이터 유지
- 입력 유효성 검사

## 실행 방법
index.html 파일을 브라우저에서 직접 열거나 VS Code Live Server 확장을 사용하세요.

## 사용된 GitHub Copilot 기능
- Step 1: 인라인 제안 (Tab으로 수락)
- Step 2: 에이전트 모드 (Ctrl+Alt+I → Agent)
- Step 3: 인라인 채팅 (Ctrl+I)
- Step 4: 커스텀 지침 + 커스텀 에이전트
- Step 5: 스마트 액션 (AI 커밋 메시지)
